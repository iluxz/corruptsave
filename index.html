tutorial: how to corrupt reality 📘

  1. play normal: hit fight, earn gold, heal, buy sword, go next zone.
  2. in-game editor: change values on the right. try NaN, Infinity, -Infinity, then click apply edits.
  3. localStorage: open devtools > Application/Storage > Local Storage, edit key corruptsave_state.
  4. URL params: add ?gold=Infinity&glitch=NaN to the URL. reload applies them.
  5. console: use game.state, e.g. game.state.hp = -Infinity; game.save(); game.render().
  6. import/export: copy JSON out, mangle it, import it back.

special behavior: NaN makes systems confused, Infinity makes you ascended/broken rich, -Infinity drags you into void mode, weird names/values can trigger hidden text. experiment. 🧪
